Token compression proxy for Claude Code

The Problem

Tokens pile up. Fast.

Claude Code sends full conversation history every turn.

Tool results contain pretty-printed JSON, raw file contents, verbose command output.

A typical session can burn 100K+ tokens in minutes — most of it redundant whitespace and structure.

More tokens = more cost, more latency, faster context exhaustion.

The Solution

Each stage targets a different content type. JSON → Node.js. Prose/Code → Python sidecar.

Stage 1

JSON Minify

Strip whitespace from pretty-printed JSON. Instant, lossless.

Before

{ "name": "tamp", "version": "0.1.0", "type": "module", "dependencies": { "@toon-format/toon": "^2.1.0" } }

After

{"name":"tamp","version":"0.1.0","type":"module","dependencies":{"@toon-format/toon":"^2.1.0"}}

Typical saving: ~30-50% on structured data

Stage 2

TOON Encoding

Array-of-objects → columnar format. Massive wins on tabular data.

JSON (334 chars)

[{"name":"a.js","size":1024}, {"name":"b.js","size":2048}, {"name":"c.js","size":512}]

TOON (165 chars)

name[3]{a.js|b.js|c.js} size[3]{1024|2048|512}
-50.6%

on real package.json tool result

Stage 3

LLMLingua-2

ML-based prompt compression. Removes redundant tokens while preserving meaning.

Input: compress.js source code

4,630 chars → 2,214 chars

-52.2%

Input: ls -la command output

Architecture

Transparent HTTP Proxy

Claude Code
→
tamp:7778
→
Anthropic API

Intercept

POST /v1/messages only. All other routes pass through untouched.

Compress

Last user message → tool_result blocks get compressed per content type.

Forward

Rewrite Content-Length, forward to upstream API. Response streams back untouched.

Safety

Bodies over 256KB bypass compression. Parse errors fall through gracefully.

Usage

3 lines to start

# Terminal 1: Start the proxy $ node index.js [tamp] proxy listening on http://localhost:7778 # Terminal 2: Point Claude Code at it $ export ANTHROPIC_BASE_URL=http://localhost:7778 $ claude

No config files. No code changes. Just an environment variable.

Compression happens silently. Claude sees the same tool results, just smaller.
